##ADR-001: Pipeline Architecture
Date: {{ today }}

###Status: Accepted

###Context
We need to process data from four sources (CSV, JSON, text, Excel) for Newham Public Library. The data has quality issues and needs to be cleaned before it can be used for analysis.

###Decision
We will use a medallion architecture with three layers:<br>

###Bronze - raw data ingested exactly as received<br>
Silver - cleaned and validated data<br>
Gold - analysis-ready aggregations<br>

###Reasons<br>
Provides simple, clear data flows.<br>
Defined points for data cleansing, validation, combination and consilidating prior to business use.<br>
Give defined user access roles, at approriate level, and options for segregating sensitive data.<br>

###Consequences<br>
Raw data is always preserved in bronze - we can reprocess if cleaning logic changes.<br>
Silver is the trust boundary - gold always reads from silver, never bronze.<br>
Gold is the user accessable environment with specific tables for reporting and analysis.<br>
